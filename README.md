# 🌐 Streamlit UI Web Generator

Aplikasi *playground* interaktif berbasis Python & Streamlit untuk mengeksplorasi, menguji, dan mempelajari struktur komponen web modern (HTML, CSS, dan JavaScript) secara *live*.

Project ini dibuat sebagai wadah eksperimen (*learning sandbox*) untuk memahami integrasi komponen frontend di lingkungan Python tanpa perlu konfigurasi *build tools* frontend yang rumit.

---

## ✨ Fitur Utama

- **Live Preview Instan:** Eksekusi dan visualisasi kode HTML, CSS, dan JS secara real-time.
- **Kategori Komponen UI:** Templat dasar untuk Navbar, Hero Section, Pricing Cards, Form, Drawer, hingga Alert Badges.
- **Interactive Syntax Editor:** Edit variabel atau gaya tampilan langsung dari antarmuka aplikasi.
- **Ready-to-Copy:** Tab khusus untuk menyalin kode bersih (*clean code*) yang siap ditempel ke proyek nyata.
